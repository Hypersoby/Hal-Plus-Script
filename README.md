## À propos

HAL+ est un script CSS conçu pour améliorer l'apparence et l'expérience utilisateur sur le portail HAL ainsi que plusieurs portails partenaires.

Le projet apporte :

✨ Une interface modernisée  
🎨 Une personnalisation avancée  
⚡ Une meilleure lisibilité  
🧩 Une compatibilité multi-portails  
🔄 Des mises à jour simplifiées

## Fonctionnalités

- Mode visuel modernisé
- Personnalisation complète des couleurs
- Plusieurs palettes intégrées
- Création de thèmes personnalisés
- Compatible Stylus
- Compatible HAL Inria
- Compatible HAL INRAE
- Compatible SHS
- Mises à jour automatiques
- Script léger et non intrusif
